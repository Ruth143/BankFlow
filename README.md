# BankFlow
Application locale d’analyse financière personnelle : import et consolidation de relevés multi-comptes, catégorisation des transactions, détection des transferts internes, dashboard global et prévision budgétaire. 


## Objectif
Application locale de consolidation et d’analyse de relevés bancaires multi-comptes.

## Problème traité
Une personne peut détenir des comptes dans plusieurs banques. Les dépenses, revenus et virements internes sont dispersés, ce qui complique une vision financière globale.

## Solution
BankFlow importe plusieurs relevés bancaires, standardise les transactions, détecte les transferts internes et fournit une vue consolidée des finances.

## Fonctionnalités
- Import PDF CSV et Excel multi-fichiers
- Gestion de plusieurs comptes et banques
- Consolidation des transactions
- Déduplication
- Catégorisation des dépenses
- Détection des transferts internes
- Dashboard global
- Budget et prévision des dépenses

## Stack technique
Python, pandas, SQLite, Streamlit, Plotly, scikit-learn.

## Confidentialité
Les données bancaires réelles ne sont pas versionnées ni envoyées vers un serveur externe. Le projet utilise uniquement des données fictives dans le dépôt.
